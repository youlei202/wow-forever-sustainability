# What this campaign adds

The previous paper already supplied the mathematical completion interface and a
selected native trinket example. This campaign evaluates that interface as a
reusable decision service, tests it on prospectively registered native menus,
and audits the statistical event on which its certificates depend. It does not
claim a new completion theorem or originality for a generic concentration bound.

| Before this campaign | New executable capability and evidence |
|---|---|
| Readable specialised reference implementation | Equivalent exact-rational CP-SAT and persistent SAT/PB encodings, witness validation, separate fixed/unknown-frontier tasks, and exhaustive correctness gates |
| A compiled family could answer target queries | Matched repeated-query services: fresh solves, cached solves, full interfaces, incremental SAT and target-driven maximal-completion caching; compilation, verification and representation costs included |
| A selected old native obstruction | Sixteen metadata-registered finite menus from four actually executed classes, frozen target predictions and 28,049,408 fresh confirmation battles |
| A negative completion result | Separate value-only and history/target/helper obligation relaxations, attributing necessity and sufficiency without deleting physical configurations or power constraints |
| An existence witness selected on prediction means | Its independent confirmation is tracked separately from the existence of a replacement witness; failed and unresolved constructions remain visible |
| Selected thresholds | Valid deterministic propagation from the inherited event to whole parameter boxes, plus four prespecified tolerance levels for all new base queries |
| Large server archives | Compact means/covariance/N and a portable, independently implemented exact subset oracle, allowing key decisions and certificates to be recomputed without the simulator |
| Certificates tied to displayed target examples | A two-antichain certificate service for arbitrary targets inside the same fixed contract; 192 registered answers and 73,728 target masks independently checked; no new sampling or alpha |

The inherited trinket obstruction is a reproduction, not new physical evidence.
The inherited glove result is a new all-width target-specific consequence of old
data: both histories can still admit some gain, yet a named future target is
excluded after one history and admitted after another throughout a certified
parameter box. Its stronger source-only obstruction is a post hoc consequence
of that old event, not a newly confirmed catalogue.

The new native base panel contains 128 correlated target queries across 16 menus.
The 64 expanded-menu rows are nested comparisons in eight of those menus; they
are not 64 new independent experiments. Task projections and tolerance levels
reuse the same confirmation event and spend no additional alpha. Their counts
must not be pooled as independent samples.

The exact timing models exported from old or new native means create no further
native evidence. Synthetic tables validate encodings and computational behavior;
they do not establish class/race coverage. The campaign does not rewrite the
paper, establish live-game prevalence, optimise combat policies, or validate
unmeasured future equipment.
