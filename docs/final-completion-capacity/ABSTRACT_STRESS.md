# Exact abstract stress checks

`ABSTRACT_STRESS.csv` and `.json` contain43 mathematical cases, generated by
`fc_abstract_stress.py`. They add zero native calls and zero class/race coverage.
The axes are deterministic model variations, not fits to future native outcomes.
They supplement rather than replace the required native diversity tests.

Unless varied, the initial optimum is1, partner span.044, headroom h=.05,
gain g=.01, relevance e=.05, and incoming minimum increment lambda=.0502.
Every combination is considered. Value capacities use exact rational attainable
intervals. Retention upper bounds additionally use the unavoidable old-primary
frontier bound1+e. A displayed full-source path establishes equality only when
it attains that upper bound; a failed path is not an impossibility certificate.

Changing gap location while keeping the same span reveals why value bounds
do not automatically establish retention. The low-cluster and uniform spectra
have exact retained capacities5 and2. Two further gap-location cases retain
only intervals[0,2] and[4,5] from the current witness search. These unresolved
intervals remain explicit. The separate four-partner continuous proof gives
value capacity3 versus retained capacity2; this is not inferred from failed
search.

Two final boundary rows prevent overinterpretation. A physical one-channel
amplitude model has identical normalized behavior shares at every release:
D=0, so the joint objective with positive distance threshold admits zero
updates despite positive value capacity. A two-task example with partner
vectors(0,.044) and(.044,0) reverses the ordering across tasks; it has no common
positive-slope scalar completion ordering, so the scalar theorem is marked
not applicable and no numeric capacity is asserted.

Of the43 rows,36 have matching general value/retention bounds, three have
unresolved retention intervals, one has invalid initial source obligations,
one uses the separate continuous L counterexample proof, one specifies the
exact D=0 boundary, and one is outside the scalar task assumptions. All of
these are abstract evidence, not native stress-test completion.
