## What this campaign changes

The campaign searches mechanisms and objectives before choosing a manuscript claim. It measures actual response tensors and complete declared combinations, including event changes, strategy and task tradeoffs, and limited multi-slot interactions. It may conclude that source retention is rarely decisive in these worlds or that a known planning method is sufficient. It does not inherit the previous three-mechanism stopping rule or require a native realization of the quadratic/repair-cascade constructions.

The operational distinction is a changed design decision under declared, comparable information, candidate sets, release width, gain requirements and total publication budget. A response can be nonlinear, statistically precise, or non-rank-one without changing any decision. Conversely a simple low-dimensional mechanism can matter if it changes which actual update can safely be released.

## Interpretations not accepted without new evidence

- The old 51-context gap/dense result is not native evidence for the manuscript's stronger retention-driven separation. The archived finite optima coincide with retention removed.
- Empty event-probe confidence-supported histories do not establish that additive responses are necessary for expansion.
- Matching only current maximum DPS does not match the full source state. Matching the complete sufficient state in a fixed response model cannot produce different future feasibility.
- A proposed power ceiling is not permission to delete unsafe physical pairings. A candidate with any legal cap-violating pairing fails global power unless a separately fixed admission rule is the treatment.
- Increasing B or deleting the unchosen first action changes permissions. Such improvements cannot be credited to a superior same-permission planner.
- Higher rank, more species/classes/seeds, arbitrary source labels, and longer logs do not independently establish meaningful content or importance.
- A finite-grid exclusion is not a continuous-domain impossibility. An exact solve of estimated means is not a population certificate.
- Reviewer assertions of originality, citation omissions, model necessity or external-domain relevance are unverified judgments. Their numerical review scores are not the search objective.

## Five propositions to challenge empirically

These are hypotheses, not preregistered positive claims. Development can change them; confirmation must freeze the final scope and contrasts.

| Proposition | Useful falsification or competing explanation | Consequence if supported |
|---|---|---|
| At near-real parameter scales, resource/timing interactions make source retention reduce capacity beyond value-only restrictions. | Check initial validity and the inactive envelope `r0(s)>=tau-e`; expand weak actions, all partners and policies; remove the interaction using a labeled fitted control. | A designer must inspect source-conditioned responses, not only each candidate's winning DPS. |
| A currently equally strong legal first release can change feasible continuation under common future candidates and fixed B. | Keep the unchosen first release as a later repair; match first gain and remaining headroom; start exact continuation from the actual released subset. | Current selection needs lookahead/source-state information. If it vanishes, the original effect was missing repairs or strength rationing. |
| Some failure is due to coordination width, whereas other failure is a genuine finite source-profile exclusion. | Compare B=1,2,4,n with equal total-item accounting; verify helpers survive the terminal frontier; enlarge the repair menu. | Choose a wider release only when it repairs the measured cause; avoid spending coordination budget on impossible target levels. |
| Native task/policy crossing changes retained uses or the admissible release, beyond every reasonable fixed-weight one-step scalarization. | Sweep scalarization weights; include policy reoptimization; test whether one configuration still covers every task. | The task distribution and policy permissions become explicit design inputs. If a simple scalar baseline resolves it, no new algorithm is needed. |
| Individually cap-safe new components can jointly violate a cap or change old-source usefulness when both expanding slots are allowed. | Measure complete new-new combinations; compare additive/separable prediction to native cells; account for all old combinations and realistic rule cost. | Release approval must assess joint configuration incidence, not independent item budgets. A failure only in stress ranges limits practical relevance. |

A separate H/C branch should test whether a fixed-peak addition changes an actual task/policy choice or closes a stated performance gap. Reproducing R6 damage-channel packing is a control, not a fresh central discovery.
