# Research integrity and storage

Keep maintained code, configurations, tests, and documentation here.
Version notebooks under notebooks/ with their executed figure and table outputs,
as explicitly requested by the user; do not strip these outputs before pushing.
Do not add paper/, manuscript sources, manuscript PDFs, or manuscript-containing
archives to the repository or GitHub release assets. Keep manuscripts local-only.
All environments, external dependencies, imported inputs, datasets, logs, caches,
standalone generated figures/PDFs, and review archives belong under WOWFS_WORK_ROOT.
Use scripts/env.sh to configure caches before running Python or tests.

Abstract finite-model results must never count as native Forever results or
executed class/race coverage. Missing runs are `not_run`, not zero performance.
Preserve failures, unresolved outcomes, denominators, and solver bound directions.
Do not claim originality from an unreviewed construction or generic concentration
inequality. Same-dimension generic rules contain structured additive rules.

Do not change a frozen run in place. Resume checks configuration and source hashes.
Keep native engine integration blocked until an actual executable engine and its
provenance are available. No public submission or invented identity. Push only when requested by the user.
